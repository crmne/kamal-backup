## Technical check (live site, 2026-11-13)

What's right: every sitemap URL answers 200 with one h1, a self-referencing canonical, descriptions under 160 characters, JSON-LD that parses (Organization, WebSite, WebPage, TechArticle, BreadcrumbList), Twitter and Open Graph tags. No broken internal links. http and www redirect to https with 301. CLS 0 to 0.004, LCP under 0.5 s on a phone, pages about 180 KB, no sideways scroll at 390 px.

What was wrong, and what this pass did:

| Issue | Done |
|---|---|
| Home title "kamal-backup Documentation \| kamal-backup" repeated the name and said nothing about backups | `seo.title` "Add scheduled Rails backups to Kamal" (the hero's own words) |
| Home description didn't name the databases | Names PostgreSQL, MySQL, or SQLite |
| "Docs Deployment" (how this docs site is built) was indexed and in the sitemap | `noindex: true`; it stays in the sidebar |

Proposals:

- og:image as a PNG (above).
- `/about/` has no internal links.
- `/next/` is indexable with self-canonicals and its sitemap is in `robots.txt`: a theme change in crmne/jekyll-vitepress-theme (`noindex` or canonical to the stable page).
- These fixes are on `master`, which the docs workflow publishes at `/next/`; they reach `/` with the next release tag.
