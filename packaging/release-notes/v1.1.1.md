## Ruby 4.0.9 in the accessory image

kamal-backup 1.1.1 moves the accessory image to Ruby 4.0.9, which fixes regular-expression security problems, and pins that exact version so a build is reproducible. Nothing changes in how you run backups.

### Fixed

- **The accessory image runs a patched Ruby.** It's built on `ruby:4.0.9-slim` instead of the floating `ruby:3.4-slim`, and the gem's tests and RuboCop run on the same version. By @crmne.

### Install

```ruby
gem "kamal-backup", "~> 1.1"
```

The accessory image is `ghcr.io/crmne/kamal-backup:1.1.1`, and the stable `latest` tag now points to 1.1.1.
